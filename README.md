# Lector de encuestas — versiones

Este repositorio solo publica los instaladores de Windows del **Lector de encuestas**.
No contiene código ni datos.

## Instalar

1. Abre la sección **Releases** y descarga el archivo `lector-encuestas-X.Y.Z-setup.exe` de la versión más reciente.
2. Ábrelo. Si Windows muestra «Windows protegió su PC», elige **Más información → Ejecutar de todas formas** (el instalador aún no está firmado).

## Actualizaciones

Una vez instalada, la aplicación revisa si hay versiones nuevas y te avisa. Nunca se actualiza sola:
tú decides cuándo descargar y cuándo reiniciar. Puedes desactivar el aviso en **Personalización → Actualizaciones**.
